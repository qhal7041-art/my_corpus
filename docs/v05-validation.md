# v0.5 검증: 참조 핵심도와 전체 결과 내보내기

2026-11-17, Linux x86_64 / Python 3.12.14 / PyQt6 6.12.1 / openpyxl 3.1.5.

```bash
python -m pip install -e '.[test]'
QT_QPA_PLATFORM=offscreen python -m pytest -q -W error
```

기존 49개 테스트를 유지하고 핵심도/내보내기/Qt 흐름 테스트를 추가했습니다. `git diff --check`도 확인합니다. 실제 Qt 위젯·QThread·이벤트 루프를 사용했으며 파일 선택 대화상자만 자동화했습니다. 네이티브 Windows/macOS 창의 수동 검증은 아닙니다.

최종 전체 회귀: **72 passed in 15.28s** (`-W error` 포함). 핵심도/내보내기/신규 UI 23개 테스트도 별도로 통과했습니다. offscreen/Fontconfig 캐시 안내는 있었지만 Python 경고를 오류로 처리한 검증은 통과했습니다.

## 핵심도

- 2×2 관측표의 G²·Pearson χ²를 50자리 Decimal 계산과 대조했습니다. 일반 표, 한쪽 0, 동일 비율, 구조적 0 열을 검산하고 대상/참조 교환 대칭성과 방향도 확인했습니다. Yates 보정은 적용하지 않습니다.
- 한쪽에서만 나온 N-gram을 합집합에 포함하고, 같은 차수의 전체 N-gram 수를 분모로 사용했습니다. 낮은 기대빈도·최솟값·방향을 확인했습니다.
- 전체 수가 0인 쪽을 설명하는 빈 결과를 저장하고 동일 코퍼스 비교는 0/동일을 반환하는 것을 확인했습니다.
- 실제 파일·JSON 추출·형태소 저장 경로를 거쳐, 서로 다른 대상/참조 JSON 필드가 동일 분석기 설정으로 비교되는 것을 확인했습니다. 이 테스트의 형태소 엔진만 결정적 대역이고, 기존 실제 Kiwi 테스트도 유지합니다.
- 옵션·버전·사전·전처리 불일치 차단, 경로/기본값 차이 허용, 외부/버전 미고정 생산자의 사용자 확인, 쌍 변경 시 확인 해제를 검증했습니다.
- 같은 DB/공통 설정은 N-gram 집계를 재사용하고 G²↔χ² 변경은 다시 집계하지 않았습니다. n 또는 DB 바이트 변경 시 해당 캐시를 다시 만들었습니다.
- 기대빈도 5 미만 전용 조회가 전체 후보에서 필터링한 뒤 상위 제한을 적용하는지 확인했습니다. 계산/SQL/미리보기 작업 취소 시 미완료 파일을 남기지 않습니다.

## 내보내기

- 형태소, 연어, N-gram, 핵심도의 CSV/XLSX를 실제 생성한 뒤 csv/openpyxl로 다시 읽었습니다. 한글/BOM, 열 이름, 토큰/품사, 빈도/점수, 설정과 두 핵심도 분모를 대조했습니다.
- UI 미리보기가 10행인 1,205종 결과에서 1,205행을 내보냈습니다. 낮은 기대빈도 필터 중에도 전체 후보를 내보내는 별도 GUI 실험을 수행했습니다.
- Excel 문자열은 수식이 아닌 문자열 타입으로 저장합니다. CSV 보호 옵션의 앞 `'` 추가 여부와 원문 모드를 대조했습니다.
- Excel 시트 행 한도를 시험용으로 낮춰 자동 시트 분할을 확인했습니다. 긴 설정 문자열을 여러 부분으로 저장·재조합해 원래 값과 대조했습니다. 본문 셀 한도를 초과하면 기존 파일을 유지하고 실패하며, CSV에는 전체 문자열이 보존됩니다.
- 스트리밍 쓰기 도중 취소와 XLSX ZIP 압축 진입 시 취소를 실행했습니다. 부분 출력과 openpyxl XML 임시 파일을 정리하고 기존 출력을 유지했습니다. ZIP 아카이브도 명시적으로 닫아 취소 시 파일 핸들이 남지 않도록 했습니다.
- CSV와 설정 JSON의 두 번째 파일 교체에 실패하도록 주입해 두 기존 파일의 바이트가 모두 복원되는 것을 확인했습니다. 복원 자체에 문제가 있으면 백업을 삭제하지 않고 위치를 알립니다.
- 원본 말뭉치/DB 덮어쓰기 차단, 새 설정을 편집하거나 API 키를 입력해도 저장된 결과의 설정만 내보내고 키는 포함하지 않는 것을 검증했습니다.
- 전체 회귀에서 제3자 SDK를 직접 사용하는 시험의 표준 출력 파이프·HTTP 연결도 명시적으로 정리했습니다. 앱은 해당 SDK를 별도 작업 프로세스에서 실행하는 기존 구조를 유지합니다.

## 실제 Qt 창에서의 추가 규모 실험

대상·참조 각각 10,000줄의 합성 사전 분석 TXT를 저장 결과로 준비하고 실제 통계/내보내기 창을 실행했습니다. 형태소 분석기는 호출하지 않았습니다. 5ms Qt 타이머로 작업 중 이벤트 처리를 확인했습니다.

| 항목 | 관측 결과 |
| --- | --- |
| 대상 / 참조 발화 | 10,000 / 10,000 |
| n=2 전체 N-gram | 20,000 / 20,000 |
| 합집합 후보 | 2,501종 |
| 최소 기대빈도 5 미만 | 1,500종 |
| 최초 비교 | 약 0.423초, Qt 타이머 40회 |
| 지표 변경 후 집계 재사용 | 두 집계 모두 재사용, 약 0.054초 |
| 낮은 기대빈도 전용 조회 | 화면 10행 모두 경고 항목 |
| 해당 필터 중 CSV 저장 | 전체 2,501행 + 설정 JSON, BOM 확인 |
| 형태소 XLSX 저장 | 전체 30,000행 + 분석 설정 시트 |
| XLSX 쓰기 | 약 2.314초, Qt 타이머 455회 |
| 같은 XLSX에 다시 저장하다 취소 | 기존 파일 SHA-256 동일, 부분 파일 없음 |

시간은 해당 작은 합성 자료에서 관측한 값이며 실제 연구 말뭉치의 성능 보장은 아닙니다. 생성한 XLSX의 실제 행 수를 다시 세었으며, 한글 UI·핵심도 표·경고 필터·내보내기 완료 화면도 이미지로 렌더링해 확인했습니다.

## 범위와 한계

핵심도는 저장된 형태소 스냅샷을 비교하며 현재 원본의 변경을 자동 재분석하지 않습니다. 비교할 분석기/사전/옵션이 다르면 동일 설정으로 형태소 분석한 결과를 먼저 선택해야 합니다. 외부 생산 과정과 바른 원격/로컬 모델의 고정되지 않은 부분은 사용자 확인을 기록합니다. 실제 바른 API/로컬 키 인증, UTagger 네이티브 모델 정확도와 Windows/macOS 네이티브 UI는 이번 검증에 포함하지 않았습니다.

내보내기는 전체 행을 처리하지만 한 번 읽는 발화의 토큰 배열과 설정 문자열은 메모리에 들어갑니다. Excel 셀 제약은 우회/절단하지 않습니다. API 키는 결과 DB/내보내기 설정에 저장하지 않습니다. 강제 OS 종료나 파일 시스템 장애까지 두 출력 파일을 하나의 원자 트랜잭션으로 보장하지는 않으며, 정상 취소·쓰기 실패·교체 실패 복원 경로를 검증했습니다.
