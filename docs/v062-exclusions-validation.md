# v0.6.2 통계 제외 필터 검증

2026-11-20, Linux / Python 3.12 / PyQt6 offscreen에서 검증했습니다.

- 전체 테스트 `python -m pytest -q -W error`: **87 passed**. 제외 필터를 위한 테스트 9개를 추가했습니다.
- 사용자 예시를 합성 형태소 TXT로 재현했습니다. `" 동일하 ㄴ 것 ” ?`에서 문장부호를 제외한 3-gram은 `동일하 ㄴ 것`, 빈도 1, 전체 3-gram 수 1입니다. 추가 목록에 `것`을 입력하면 3-gram이 생성되지 않는 이유가 표시됩니다.
- Unicode 문장부호, 품사와 무관한 제외, 복합 문장부호 `?!`, `C++`·수학기호·이모지 보존, 특정 형태소의 정확 일치, 제외 목록 정규화와 잘못된 설정 거부를 확인했습니다.
- 연어는 `밥 " 먹`에서 부호를 제외해도 원래 거리를 유지합니다. 우측 범위 1에서는 공기 0, 범위 2에서는 `밥→먹` 공기 1입니다. 토큰 빈도·슬롯 주변합·전체 슬롯 수에도 제외가 적용됩니다.
- 핵심도의 양쪽 분모에서 동일한 항목이 제외되며, 제외 조건이 바뀌면 캐시를 재사용하지 않고, 같은 제외 조건으로 G²에서 χ²로 바꾸면 집계를 재사용하는 것을 검증했습니다.
- 실제 Qt 창에서 입력→통계 계산→프로젝트 저장→다시 열기를 수행하고 문장부호 체크와 추가 목록의 복원을 확인했습니다. CSV 설정 JSON에 두 제외 설정이 기록되는 것을 확인했습니다.
- 원본 형태소 DB의 바이트가 필터 적용 전후 동일한 것을 확인했습니다. 합성 예시를 Qt로 렌더링했고, 1024×640 창에서 설정 영역에 가로 스크롤 없이 표시되는 것을 확인했습니다. Windows/macOS 실제 화면 배율은 별도 확인 대상입니다.
