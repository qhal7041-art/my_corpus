# v0.3 분석기 연동 검증

2026-11-16, Linux / Python 3.12.14. 설치한 SDK: bareunpy 2.1.0, pyutagger 1.0.1.1031. 기존 Kiwi 0.24.1과 JSON/TXT/Excel 입력 지원 유지.

## 근거와 확인 범위

- [바른 SDK 공식 배포 설명](https://pypi.org/project/bareunpy/): HTTPS 호스팅 API, 인증 헤더, 보정 옵션, 서버 사용자 사전 이름, 공식 Connect RPC 요청/응답 타입을 확인했습니다. 다운로드한 PyPI 아티팩트는 배포 메타데이터의 SHA-256과 대조했습니다. `bareun.ai/analyze` 페이지는 이 환경의 프록시에서 403으로 열리지 않아 내용을 읽지 못했습니다.
- [pyutagger 공식 배포 설명](https://pypi.org/project/pyutagger/): 래퍼 설치 외 `install_utagger`로 바이너리·모델을 받는 단계, 홈 디렉터리 등록 파일, `utagger_loader/load/pos` 사용법을 확인했습니다. SDK 소스의 전역 `chdir`, 설정 미존재 시 `sys.exit`, 네이티브 라이브러리 로딩을 확인하고 별도 프로세스로 격리했습니다.
- UTagger 다운로드 코드는 HTTP 배포 목록을 사용하고 새 아티팩트에 체크섬 검증을 강제하지 않습니다. 이 경로를 자동 실행하거나 검증을 우회하지 않았습니다. 현재 환경에는 UTagger 네이티브 모델이 없습니다.
- 바른 키는 사용자 입력 전용으로 구현했습니다. `.env`, 환경 변수, 사용자 키 파일을 만들지 않았습니다. 실제 인증 가능한 키를 제공받지 않아 실제 바른 서버 분석은 미검증입니다.

## 수행한 검증

```bash
python -m pip install -r requirements.txt
python -m pip install -e '.[morphology,bareun,utagger,test]'
QT_QPA_PLATFORM=offscreen python -m pytest -q
```

- **32개 테스트 통과** (최종 회귀 실행: 15.76초), `git diff --check` 통과.
- 실제 바른 SDK의 protobuf 요청을 만들고 실제 SDK 응답 파서를 사용해 형태소/품사를 읽었습니다. 네트워크 전송 부분만 대역으로 대체해 HTTPS 주소·30초 제한·인증 헤더·보정 옵션·서버 사전 이름 전달을 확인했습니다.
- 바른 API 키 직접 입력 칸의 비밀번호 표시, 키 미입력 시 실행 비활성화, 분석기 전환 시 옵션 가시성, 설정 저장/복원 시 키 제외, 창 닫을 때 키 지우기를 Qt에서 검증했습니다. 입력 창을 offscreen으로 렌더링해 한글과 가림 표시도 확인했습니다.
- API 오류가 키를 포함해 반환되어도 UI로 전파되는 오류에는 키가 없음을 확인했습니다. 키를 분석 설정에 넣으려 하면 저장을 거부합니다.
- 작업자에서 인증 값을 런타임 인자로만 받고 프로젝트 JSON·SQLite 파일·설정/캐시 키에 포함하지 않는지 검사했습니다. 작업 종료 후 분석기 close와 작업 함수 참조 해제를 수행합니다.
- 바른은 서버 모델/계정 사전 버전을 확정할 수 없어 자동 캐시를 사용하지 않습니다. 동일 설정으로 다시 실행해도 서로 다른 결과 파일을 보관합니다. 저장 결과는 키 없이 읽을 수 있습니다.
- UTagger IPC 프로토콜은 실제 자식 Python 프로세스로 검증했습니다. 모델 호출 부분을 대역으로 대체해 품사/어깨번호 보존·부모 작업 디렉터리 유지·자식 종료·응답 제한 시간 초과 시 종료를 검증했습니다.
- 실제 설치된 pyutagger를 자식 프로세스에서 실행해 등록 파일/모델 미존재가 주 앱 종료 대신 일반 오류로 처리되는 것을 확인했습니다.
- UTagger 모델 파일 내용 변경 시 모델 지문이 달라지는 것을 확인했습니다. 네이티브 모델을 실제로 로드해 한국어를 분석한 검증은 아닙니다.
- 기존 Kiwi, UTF-8/CP949 TXT, XLSX/XLS, 프로젝트 복원, 3,000개 JSON 탐색·추출·응답·취소 회귀 테스트도 통과했습니다.

## 직접 사용

최신 코드를 받은 후 `python -m pip install -r requirements.txt`를 실행하세요. 바른은 **형태소 분석… → 바른 → API 키 입력 → 분석**입니다. 키는 이 창에서만 유지되고 다음에 열면 다시 입력합니다. UTagger는 공식 배포 라이브러리·모델을 설치·등록한 PC에서 해당 버전을 선택하세요.

실제 API 키로 바른 원격 분석과 공식 네이티브 모델로 UTagger 출력 검증은 남아 있습니다. 이번 검증 결과를 서비스 인증 성공이나 네이티브 분석 정확도 검증으로 해석하지 않습니다.
