# 1단계 검증 기록

2026-11-16, Linux 클라우드 환경 / Python 3.12.14 / PyQt6 6.12.1.

## 실행

```bash
cd /workspace/my_corpus
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install -e '.[test]'
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q -s
```

실제 Qt 위젯과 QThread, Qt 이벤트 루프를 사용했습니다. GUI를 대체한 가짜 작업자는 사용하지 않았습니다. 파일 선택 대화상자의 반환 경로만 자동화했습니다. 화면은 offscreen으로 렌더링한 뒤 이미지로 확인했습니다 (한글 레이블, 트리, 경로, 발화 ID, 미리보기 표시). 실제 사용자의 데스크톱에서 마우스로 모든 흐름을 수동 검증한 것은 아닙니다.

최종 실행: **14 passed in 3.63s**. `git diff --check`도 통과했습니다. offscreen 플러그인의 `propagateSizeHints` 안내와 Fontconfig 캐시 쓰기 경고는 있었지만 한글 렌더링과 기능 테스트는 완료했습니다.

## 통과 항목

- 이름 / 저장 경로 대화상자를 통한 새 프로젝트 생성 및 파일 생성
- 대상과 참조의 서로 다른 폴더·필드 선택/저장/다시 읽기
- 프로젝트 파일에 분석기 옵션·분석 설정·결과 목록 보존
- 프로젝트와 말뭉치 폴더 동반 이동 후 상대 경로 복원
- 없는 폴더 안내 → 폴더 연결 버튼 → 재연결 → 필드 유지 → 재저장
- 혼합 JSON 구조의 합집합, 배열 내 여러 발화의 파일 존재 수 중복 방지
- 손상 JSON, UTF-8 디코딩 오류, 비표준 NaN을 실패로 집계하고 정상 파일 계속 처리
- 배열 루트, 특수문자 키, BOM, null/숫자, 누락 필드, 빈 배열 처리
- 미리보기 100행/500자 제한, 원본 파일 바이트 불변 확인
- 실제 필드 선택 신호로 추출 시작, 다시 열 때 저장 필드로 자동 미리보기
- 처리 중 Qt 타이머 응답, 취소 버튼으로 중단, 취소 후 재실행
- 탐색 중 창 닫기 시 스레드 종료를 기다리고 창 종료

테스트 프로세스의 `QApplication`은 세션당 하나를 유지합니다. 반복 GUI 테스트 중 앱 객체를 여러 번 생성/파괴할 때 발생한 Qt 수명 문제를 테스트 픽스처에서 수정했습니다.
