# v0.6 UI 검증

2026-11-17, Linux / Python 3.12 / PyQt6, Qt offscreen에서 검증했습니다.

- `python -m pytest -q -W error`: **75 passed**. 기존 72개에 UI 상호작용 회귀 테스트 3개를 추가했습니다.
- 실제 Qt 이벤트 루프로 3,000개 합성 파일의 읽기, 손상 파일 처리, 응답성, 취소, 재실행, 저장/복원을 다시 검증했습니다. 기존 형태소·연어·N-gram·핵심도·전체 내보내기 테스트도 통과했습니다.
- 필드 경로 검색 시 조상 노드가 펼쳐지고, 검색을 지우면 구조가 복원되며, 저장된 선택 필드·추출 결과가 유지되는 것을 검증했습니다.
- 저장 목록에서 참조 말뭉치의 형태소 결과를 실제로 열었습니다. 원본 TXT를 삭제하고 분석기 초기화를 금지한 상태에서 저장된 형태소 2개와 참조 역할이 복원되는 것을 검증했습니다.
- 접힌 기록의 오류 발생 시 펼침, 다시 접기, Ctrl+C용 TSV 복사, 숫자 셀의 숫자 정렬을 검증했습니다.
- 프로젝트 화면 1280×820, 형태소·통계 배치, 내보내기 창을 Qt로 렌더링했습니다. 프로젝트·통계 화면은 1024×640에서도 실제 창 크기가 유지되는 것을 확인했습니다. 작은 창의 설정과 자료 영역은 스크롤하며, 결과 표는 가로 스크롤합니다.
- 배포용 wheel을 빌드하고 두 SVG 아이콘이 패키지에 포함되는 것을 확인했습니다.
- README의 화면 예시는 대상·참조 각 12발화의 합성 JSON을 실제 Kiwi로 분석하고 핵심도 G²를 계산한 결과입니다. 설정·원문·결과는 임시 프로젝트에서 생성했습니다.

이번 검증은 Linux offscreen 렌더링과 자동 상호작용 기준입니다. Windows/macOS의 실제 화면 배율과 글꼴 조합에서는 별도 확인이 필요합니다. 테마에는 Windows 맑은 고딕 등 한국어 글꼴 대체 목록이 있으며, UI 아이콘은 패키지에 포함합니다.
