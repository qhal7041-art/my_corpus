# v0.6.1 도움말 검증

2026-11-20, Linux / Python 3.12 / PyQt6, offscreen에서 확인했습니다.

- 전체 테스트: `python -m pytest -vv -W error -o faulthandler_timeout=30` → **78 passed**.
- 추가된 3개 테스트는 분석기별 도움말의 표시/숨김, 클릭으로 열기·닫기, Tab/Space용 키보드 접근, 비활성화한 옵션의 도움말 접근, 도움말 열기 전후 설정 불변, 비밀 키가 설명에 노출되지 않음, 통계 종류에 따른 도움말 전환을 확인합니다. 분석기 초기화를 금지한 상태에서 도움말을 열었습니다.
- 형태소 화면의 네 분석기 모두 1024×640으로 렌더링했습니다. 설정 영역에 가로 스크롤이 발생하지 않으며 세로로 스크롤해 실행 버튼에 접근할 수 있습니다.
- 형태소 화면, 복합 형태소 분리 설명을 펼친 팝업, 연어 설정 화면을 Qt로 렌더링해 확인했습니다. README의 팝업 이미지는 설명 문구만 담은 화면입니다.
- Kiwi 옵션은 설치된 kiwipiepy의 tokenize 문서, 바른·UTagger 옵션은 현재 어댑터가 전달하는 설정과 대조했습니다. 연어 설명은 슬롯 주변합을 사용하는 앱의 통계 기준과 맞췄습니다. 품사 필터 후 N-gram을 묶는 기준과 연어의 원래 탐색 거리 유지도 구별해 설명합니다.

도움말은 로컬 설명만 표시하며 데이터 읽기·형태소 분석·설정 저장을 실행하지 않습니다. 계산 로직과 프로젝트 저장 형식은 바꾸지 않았습니다. Windows/macOS의 실제 화면 배율과 글꼴은 별도 확인 대상입니다.
