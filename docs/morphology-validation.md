## 검증 항목

- 기존 프로젝트 생성/복원, 3,000개 JSON 구조·추출·취소 테스트 유지
- 실제 Kiwi 사용자 사전에 `코덱스방언연구 NNP 100` 등록 후 하나의 NNP로 분석되는지 확인
- 원문·형태소/품사·원본 파일·발화 ID의 SQLite 저장과 다시 읽기
- 데이터와 설정이 같으면 모델 초기화 없이 결과 재사용
- 원문 변경, 선택 필드 변경, 옵션 변경 시 재사용하지 않고 별도 결과 생성
- 손상 JSON/Excel 오류 집계, 정상 파일 계속 처리, 실패 파일 포함 결과는 캐시 자동 재사용 제외
- 취소/분석기 실패 시 임시 DB 삭제, 완료 결과로 등록하지 않음
- 손상된 캐시는 재구축, 저장한 과거 결과는 원본이 없어도 열기 가능
- 바른·UTagger 선택 시 실행 비활성화, Kiwi 전용 옵션 숨김, 미구현/준비 사항 안내
- 실제 형태소 분석 중 Qt 타이머 응답과 취소, 재실행, 프로젝트에 옵션·사전·결과 참조 저장 및 복원
- TXT: UTF-8 BOM, CP949, 빈 줄 제외, 원문 공백 유지, 원본 줄 번호, 잘못된 인코딩 실패 처리
- Excel: 실제 `.xlsx`/`.xls` 샘플, 헤더 기반 열 선택, 중복 열 이름 구분, 숫자/null 비문자열 처리, 필드 존재 파일 수가 행 수로 중복 집계되지 않음
- Excel 행 반복 중 취소, Excel 선택 필드 복원 → 실제 Kiwi 분석 → 결과 저장/재사용 UI 흐름

캐시 무효화 및 오류 경로 단위 테스트에서는 작은 결정적 분석기 대역을 사용합니다. 실제 Kiwi 동작은 별도 테스트와 Qt 통합 테스트에서 검증합니다. XLS 샘플은 합성 자료로 xlwt 1.3.0으로 만들었으며, 런타임/테스트에서 xlwt 설치는 필요하지 않습니다.

## 실제 Kiwi 3,000개 JSON 추가 실행

`generate_corpus.py`가 생성한 실제 3,000개 파일을 모두 형태소 분석했습니다. 고정 옵션은 정규화/복합 분리/호환 자모 모두 꺼짐, 사용자 사전 없음, 전처리 없음, 발화별 처리입니다.

| 항목 | 관측 결과 |
| --- | --- |
| 처리 파일 | 3,000 |
| 성공 / 실패 | 2,996 / 4 (의도적으로 손상시킨 JSON) |
| 선택 경로 | `$.utterances[*].text` |
| 발화 | 82,980 |
| 형태소 | 912,780 |
| 분석 시간 | 약 16.94초 |
| SQLite 파일 크기 | 약 31.35 MiB |

시간/크기는 합성 자료에서 한 번 관측한 값입니다. 3,000개 형태소 실행은 서비스 함수를 직접 호출한 추가 검증이고, GUI 응답/취소 검증은 Qt 통합 테스트에서 별도로 수행했습니다. 실제 방언 원자료의 형태소 정확도를 평가한 결과가 아닙니다.

## 한계

바른·UTagger 실제 연동, 연어/N-gram/핵심도, Excel/CSV 내보내기는 아직 구현하지 않았습니다. Excel 수식 계산·암호 해제는 지원하지 않습니다. XLS는 한 시트가 메모리에 올라갈 수 있고, JSON은 한 파일이 메모리에 올라갑니다. TXT/Excel도 현재 선택 필드 하나만 분석합니다. 취소는 현재 파일 파싱/모델 초기화/한 발화 분석 완료 뒤 반영됩니다. Windows/macOS의 네이티브 UI는 검증하지 않았습니다.
